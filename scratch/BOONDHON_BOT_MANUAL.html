মূল বৈশিষ্ট্য: বন্ডহনের সাশ্রয়ী ও প্রিমিয়াম কার্ডের ডিজাইন ও উপাদান সম্পূর্ণ এক হতে পারে। এদের মধ্যে একমাত্র পার্থক্য হলো ফিজিক্যাল সাইজ (যেটি সমতল ছবি দেখে আলাদা করা যায় না)। তাই সিস্টেমটি AI Visual Embedding Search ব্যবহার করে ক্যাটালগের আসল ছবির সাথে মিলিয়ে সঠিক ক্যাটাগরি চিহ্নিত করে।

🚀 ২. বট ট্রেনিং / ক্যাটালগ ইনডেক্সিং করার নিয়ম

বটকে আপনার Google Drive-এর সব ছবি শেখানোর জন্য টার্মিনালে নিচের কমান্ড দুটি চালান:

PowerShell-এ চালান:

cd H:\Data\boondhon-git $env:GEMINI_API_KEY="আপনার_গুগল_এপিআই_কী" node scripts/build-catalog-index.js
💡 নোট: কমান্ডটি সফলভাবে চললে lib/catalog-embeddings.json নামে একটি ভেক্টর মেমরি ফাইল তৈরি হবে যা কাস্টমারের ছবির সাথে ম্যাচিং করার কাজে ব্যবহৃত হয়।

🔄 ৩. ভবিষ্যতে নতুন ছবি যোগ বা আপডেট করার নিয়ম

  1. গুগল ড্রাইভে আপলোড: নতুন কার্ডের ছবি ড্রাইভে আপলোড করে ছবিটির File ID নিন।
  2. lib/data.js ফাইল আপডেট:
    • সাশ্রয়ী কার্ড হলে AFFORDABLE_IDS অ্যারেরে শেষে ফাইল আইডি যুক্ত করুন।
    • প্রিমিয়াম কার্ড হলে PREMIUM_IDS অ্যারেরে শেষে ফাইল আইডি যুক্ত করুন।
  3. ইনডেক্স রি-রান: টার্মিনালে আবার চালান: node scripts/build-catalog-index.js (এটি আগের ছবিগুলো স্কিপ করে কেবল নতুন ছবির মেমরি ২-৩ সেকেন্ডে আপডেট করে নেবে!)
  4. পাবলিশ/লাইভ: ভিএস কোড থেকে Git Commit ও Push করলেই নতুন কার্ড লাইভ বটে কাজ শুরু করবে।
